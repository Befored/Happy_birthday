# 🎉 Подарочный интерактивный сайт на 20-летие сестры

Полноценный интерактивный одностраничный веб-квест с переходами между сценами, стильными визуальными эффектами, звуками и адаптацией под смартфоны и компьютеры.

---

```text
Happy_birthday/
│

├── style.css            # Премиальный дизайн, анимации и мобильная адаптация
├── app.js               # Интерактивная логика (фонарик, покер, карусель, салют)
├── config.js            # ✍️ ЗДЕСЬ ТЫ РЕДАКТИРУЕШЬ ВСЕ ТЕКСТЫ И ПОЗДРАВЛЕНИЯ!

    ├── flashlight.svg       # Фонарик
```

## ✍️ Где и как редактировать тексты

Все тексты, имена, цитаты, пожелания и шутки вынесены в **`config.js`**.  
Открой `config.js` в любом текстовом редакторе (Блокнот, VS Code, Sublime Text и т.д.).

### 1. Имя и возраст:
```javascript
sisterName: "Любимая Сестрёнка", // Впиши реальное имя (например "Аня", "Катя")
age: 20,
```

### 2. Экран 1 (Мафия и фонарик):
- **Скрытые фото за картами**:
  - Карта Мафии (`images/mafia.png`) скрывает реальное фото Брата (`images/ruzil.jpg`). При нажатии карта в 3D переворачивается и раскрывает личность и подпись: *«Ей теперь 20... надо быть осторожнее»*.
  - Карта Шерифа (`images/sherif.png`) скрывает фото Тёти (`images/Apa.jpg`). При нажатии переворачивается и показывает фото и подпись: *«Интуиция не врёт — моя девочка самая лучшая. Она не может быть мафией»*.
- **Мрачная обстановка без неона**: полностью убраны все неоновые контуры и яркие эффекты ниже заголовка — сцена оформлена в аутентичном темном детективном стиле.
- **Прямые углы**: все плашки сделаны строго прямоугольными.
- **Фонарик**: аккуратно лежит на столе и освещает скрытый текст протокола посередине.
- В блоке `hiddenLetter.paragraphs` находится скрытый поздравительный текст. Добавляй или меняй любые строки!

### 3. Экран 2 (Покерный стол):
- В массиве `cards: [ ... ]` описаны все 5 карт.
- Для каждой карты можно задать свой заголовок (`title`) и текст пожелания/подколки (`wish`).

### 4. Экран 3 (Фотогалерея 20 лет):
- Фон сделан тёмным и комфортным, чтобы глаза плавно переходили с тёмных страниц 1 и 2.
- `carouselPhotos`: динамические фото для круговой карусели. Карточки стали компактнее и красивее, на экране видно сразу несколько штук, и они листаются бесконечно по кругу!
- `dividerTitle` и `dividerSubtitle`: текст шутливого перехода («А теперь суровая домашняя правда...»).
- `staticPhotos`: список домашних/детских фоток в стиле полароид.
- В конце страницы оставлена только аккуратная золотая кнопка **«Пройти квест заново ↺»**, которая сбрасывает карты и свет и возвращает в начало.

## 📸 Как добавить свои фотографии сестры

1. Скопируй фотки сестры в папку `images/` (например, `images/sister_insta1.jpg`, `images/sister_baby.jpg` и т.д.).
2. Открой `config.js` и в нужных местах замени `src`:
   ```javascript
   carouselPhotos: [
     {
       src: "images/sister_insta1.jpg",
       title: "Королева красоты ✨",
       caption: "Сделано 500 дублей ради одного идеального кадра"
     },
     // ...
   ]
   ```
3. Сохрани файл `config.js` и обнови страницу в браузере (нажми **F5**).

## 📱 Адаптация под телефон (Мобильная версия)

**Да, сайт полностью адаптирован под смартфоны и планшеты:**
- **Экран 1 (Фонарик):** на телефоне фонарик управляется пальцем! Достаточно нажать на фонарик или коснуться скрытого текста — луч света следует прямо за пальцем. Для удобства также добавлена кнопка *"💡 Включить верхний свет"*.
- **Экран 2 (Покер):** карты аккуратно масштабируются под ширину экрана любого телефона. При тапе на карту снизу плавно выдвигается карточка с крупным текстом пожелания, чтобы было удобно читать.
- **Экран 3 (Галерея):** слайдер поддерживает **свайпы пальцем влево-вправо** (Touch Swipe). При нажатии на любое фото оно открывается на весь экран в высоком качестве.
- Кнопки имеют удобный крупный размер для нажатия пальцем.

## 🌐 Как бесплатно выложить сайт на GitHub Pages (за 3 минуты)

Чтобы отправить сестре красивую ссылку в мессенджер (например, `https://твой-логин.github.io/Happy_birthday/`):

1. Зайди на [github.com](https://github.com) и войди в свой аккаунт (или зарегистрируйся).
2. Нажми зеленую кнопку **«New»** (создать новый репозиторий).
3. В поле **Repository name** напиши: `Happy_birthday` (или любое другое имя).
4. Выбери **Public** и нажми **«Create repository»**.
5. На странице нового репозитория нажми ссылку **«uploading an existing file»** (или используй git в консоли).
6. Перетащи все файлы из папки `C:\Users\galav\Desktop\Happy_birthday` (включая папку `images/`, `index.html`, `style.css`, `app.js`, `config.js`).
7. Нажми зеленую кнопку **«Commit changes»**.
8. Перейди во вкладку **Settings** (Настройки репозитория) ➔ слева раздел **Pages**.
9. В пункте **Branch** выбери ветку `main` (или `master`), папку `/ (root)` и нажми **Save**.
10. Через 1-2 минуты обнови страницу — сверху появится ссылка вида:
    `https://твой-логин.github.io/Happy_birthday/`
11. Отправь эту ссылку сестре на телефон в день рождения! 🎉
